# みほん くみたて あそび (mihon-kumitate-asobi)
参考書籍 Stage I「7. 構成」7-1 (2) 実物の見本を見て構成する、をもとに、画面で練習する遊び。見本を見て、同じものを横の台紙に作る。

- `public/index.html` 単一ファイル。Cloudflare Workers（assets）で公開。
- 材料：ご石／色紙／プレート（四角の枠と、図2の矢印）／積木（正面から見た積み木）。部品 2/3/4/6。
- 見本の見せ方：見せる／はじめだけ（約5秒で紙がかぶさる）／紙でかくす。画面の下の紙のボタンで、いつでも紙をかぶせたり外したりできる。子どもが紙を押さえてめくって見ることもできる（切りかえ可）。
- 見本の出し方：すぐ出す／作って見せる（見本の部品が1つずつ置かれる）。
- 手助け 大/ふつう/小：入る範囲と、台紙の手がかり（輪郭／十字／なし）が変わる。
- 合わない位置の部品は、その場に残る（自分で気づいて置き直す）。台紙の外で離すと置き場へ戻る。
- 成功は「ことん」＋星。失敗の音や揺れなし。お祝いの強さは調整可。完成すると紙が外れて、見本と見比べられる。
- 前提：「見本に重ねる」（7-1 (1)）のアプリ「くみたて あそび」ができるようになってから使う。
- 記録・名前・声・顔は保存しない。カメラ・マイク不使用。設計: docs/spec.md
