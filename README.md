# みほん くみたて あそび (mihon-kumitate-asobi)
参考書籍「構成」7-1 (2) 実物見本による構成をもとに、画面で練習する遊び。見本を見て、同じものを横の台紙に作る。
- `public/index.html` 単一ファイル。Cloudflare Workers（assets）で公開。
- 材料 ご石／色紙／プレート、部品 2/3/4/6、手助け 大/ふつう/小。
- 見本は常に見せる。部品は回さない。
- 合わない位置の部品は、その場に残る（自分で気づいて置き直す）。台紙の外で離すと置き場へ戻る。
- 成功は「ことん」＋星。失敗の音や揺れなし。お祝いの強さは調整可。
- 前提：「見本に重ねる」（7-1 (1)）のアプリ「くみたて あそび」ができるようになってから使う。
- 記録・名前・声・顔は保存しない。カメラ・マイク不使用。設計: docs/spec.md
